# IMBoy

一个可私有化部署的即时通讯应用，支持单聊、群聊、频道、朋友圈、
音视频通话与端到端加密。

## 主要功能

- **消息** — 文字、图片、语音、视频、文件、位置，支持引用、转发、撤回与收藏
- **群聊** — 群公告、群文件、群相册、投票、日程、作业、标签与分组
- **频道** — 订阅与发布图文内容，支持评论与管理员协作
- **朋友圈** — 发布动态、评论点赞、按标签控制可见范围
- **通话** — 一对一语音与视频通话
- **端到端加密** — 消息在设备间加密传输，密钥由你自己保管，可备份与恢复
- **多语言** — 支持简体中文、繁体中文、英语、日语、韩语、俄语、
  法语、德语、意大利语、阿拉伯语

## 隐私

- 端到端加密的消息内容，服务器无法读取。
- 加密密钥保存在你的设备上，请在「设置 → E2EE 密钥管理」里做好备份。
- 详细说明见「设置 → 隐私政策」。

## 遇到问题

- 常见问题见「设置 → 帮助文档」。
- 需要联系我们，请用「我的 → 反馈建议」提交，我们会跟进处理。
