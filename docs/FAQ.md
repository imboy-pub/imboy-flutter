# 常见问题

## 消息

### 收不到消息，或者消息很慢

- 先看网络是否稳定，信号弱的时候消息和送达状态都会变慢。
- 应用长时间放在后台后，重新打开需要几秒钟恢复连接。
- 如果某条消息一直停在「发送中」，退出会话再重新进入，会触发一次状态同步。
- 还不行就重启一次应用。

### 消息发送失败了怎么办

长按那条消息，选择「重试」可以重新发送；确认不需要了就选「删除」。

### 未读数不对

先返回消息列表，再重新进入这个会话，未读数会重新计算。
如果最近换过设备或重新登录过，建议再退出登录一次、重新登录。

### 图片、视频、语音发不出去

- 确认网络正常，大文件建议在 Wi-Fi 下发送。
- 到系统设置里确认已经允许本应用使用相册、相机、麦克风。
- 文件较大时上传会比较慢，请耐心等待或稍后重试。

### 收不到新消息提醒

- 确认系统通知权限已开启。
- 确认这个会话没有被设置成免打扰。
- iOS 还需要确认「后台应用刷新」是打开的。
- Android 部分机型会自动关闭通知渠道或限制后台运行，需要在系统设置里手动放开。

## 账号与登录

### 登录不上

- 确认账号和密码输入正确，注意大小写。
- 提示登录已失效时，退出后重新登录一次即可。
- 忘记密码可以在登录页选择「忘记密码」通过邮箱或手机号找回。

### 怎么修改密码

「我的 → 设置 → 账号安全 → 修改登录密码」。

### 发现有陌生设备登录了

到「我的 → 登录设备管理」查看所有已登录的设备，
认不出来的设备可以直接删除，删除后该设备会立即退出登录。
建议同时修改一次登录密码。

## 隐私与安全

### 聊天内容是加密的吗

IMBoy 支持端到端加密。开启后，消息在你的设备上加密、在对方设备上解密，
中途任何环节都无法读取内容。密钥保存在你自己的设备里。

### 换手机以后看不到以前的聊天记录

端到端加密的消息只能用原来的密钥解开。
换设备前请先到「我的 → 设置 → E2EE 密钥管理」导出密钥备份，
在新设备上导入后即可恢复。**没有备份的话，服务器也无法帮你恢复。**

### 聊天记录存在哪里

会话和消息保存在你手机本地，用于列表展示、搜索和离线查看；
图片、视频等文件会缓存在本地目录，方便重复查看。
可以在「我的 → 存储空间」查看占用情况并清理缓存。

## 其他

### 怎么反馈问题

「我的 → 反馈建议 → 新建反馈」。为了更快定位，建议一并说明：

- 用的什么手机
- 应用版本号（在「设置 → 关于应用」里）
- 大概什么时候发生的
- 怎么操作会重现
- 如果方便，附一张截图
